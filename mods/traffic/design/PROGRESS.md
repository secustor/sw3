# sw3-traffic: progress and implementation phases

Tracking document for the trader-traffic mod. The design is in [traffic-design-research.md](traffic-design-research.md) (requirements M1–M21, S1–S45, C1–C21, W1–W11; phased plan in section 12), the build route in [mod-options.md](mod-options.md). This file tracks what is done, what is next, and what is still undecided. Update it when a phase item changes state; keep the design doc as the source for rules.

Status legend: `[ ]` not started, `[~]` in progress, `[x]` done, `[-]` dropped.

## Current state (2026-10-21)

- Design and engine research complete. Phase 0 code written (2026-10-20); E0.1 passed in the game (2026-10-21: hooks, jump, autosave, quit/relaunch/load); E0.2 passed except the `PI` key and save-growth checks. Phases 1–3 (v0.1, v0.2, v1) implemented, host-tested (44 host runs), awaiting in-game run; v1 installed in the clone with `EXP=0 TRAFFIC=1 AUTOSAVE=1`. Next: the in-game test plan below.
- Build route decided: Lua scripts under `Data/Scripts/Mods/Traffic/` plus a `traffic` module in the sw3tp `zlib1.dll` proxy (mod-options §5). Pure Lua is the fallback (option i).
- Test bench: APFS clone `~/Games/Heroic/sw3-tp-test` with `mods/traffic/install-test.sh` (`EXP=0..3`, `TRAFFIC=0|1`, `AUTOSAVE=0|1|2`, optional `OVERRIDE`, `DUMP`, `GUARD`, the v0.2 and v1 keys, `LEVEL`, `PRO_SET`, `TUNE`, `FEQ_AT`, `LOC`), `run-test.sh`, `uninstall-test.sh` (mod-options §7).
